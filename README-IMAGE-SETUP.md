# Rodriguez Verse — updated personal-image code

This package contains the complete updated `index.html`, `css/style.css`, and `js/main.js`.

## Add your own photos

Place your existing image files in the project's `assets/images/` folder with these exact names:

- `RV.jpg` — the large image in the homepage **THE GATEWAY / WHERE IDEAS TAKE FLIGHT** area
- `ADP.jpg` — the photo in the **Adventurer Profile** card
- `MJ.jpg` — the portrait in the **CURIOSITY · CRAFT · CODE** area

The website does not generate, download, or use replacement images. It references these local files only.

## How to apply

1. Make a backup of your current project folder.
2. Copy the provided `index.html` to the project root.
3. Replace `css/style.css` with the provided `css/style.css`.
4. Replace `js/main.js` with the provided `js/main.js`.
5. Keep your existing `assets/dragons/`, `assets/icons/`, and other assets folders.
6. Ensure the image names match exactly, including capitalization and `.jpg`.
7. Open `index.html` and refresh the browser with `Ctrl + F5`.

If the actual third filename includes a space (for example `M MJ.jpg`), either rename it to `MJ.jpg` or update the `src` in `index.html` to match the real filename.
